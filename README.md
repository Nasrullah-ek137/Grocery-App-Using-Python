# Royal Smart Grocery App (Python)

Royal Smart Grocery App is a **console-based Python application** designed to simulate
a real-world grocery store system. The project is built using **Object-Oriented Programming (OOP)**
concepts and provides separate **Admin** and **Customer** panels.

This project focuses on **Python fundamentals, logic building, and real-world business flow**.

## 🚀 Features

### 🔐 Admin Panel
- Secure admin login
- Add new products
- Delete existing products
- Update product details (name, quantity, price)
- View all products
- Low stock alerts
- Manage inventory efficiently

### 🛒 Customer Panel
- View available products
- Purchase products
- Add items to cart
- Automatic stock reduction
- Bill generation
- Gift system based on total bill amount
- Multiple payment modes (COD / UPI)

### 🎁 Smart Gift System
- ₹1000+ → Chocolate
- ₹2000+ → Sanitizer
- ₹10000+ → Bluetooth Earphones


## 🧠 Concepts Used
- Object-Oriented Programming (Classes & Objects)
- Encapsulation
- Data handling using lists & dictionaries
- Conditional logic
- Loops
- Exception handling
- Real-world business logic
- Menu-driven program
